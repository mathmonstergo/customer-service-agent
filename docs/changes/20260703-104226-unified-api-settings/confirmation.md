# 用户确认记录

## 当前状态

已确认 UI 方向和第一版范围，可以进入实现。

## 已知用户意图

* 新增设置菜单页。
* 统计并统一管理项目已有 API 设置。
* 智能问答会话级 API 仍然支持在会话页单独设置。
* 设置页不需要额外内部导航或子页面。
* 每个具体设置做成同尺寸卡片，卡片展示当前配置摘要。
* 知识图谱实体/关系抽取需要在设置页有显式配置入口；当前实现跟随全局 Chat 默认模型。
* 点击卡片中心后出现居中弹窗，在弹窗里编辑该设置的具体配置。
* 弹窗动效参考 iOS 系统：从对应卡片丝滑扩展为弹窗，背景随弹窗放大过程逐渐虚化。
* API Key / Token 等敏感字段，前端不能获取已填写明文，只能看到脱敏摘要或已配置状态；输入新值才覆盖旧值。
* 第一版只给 Chat 做模型拉取和测试连接；Embedding / Rerank / MinerU 先只保存配置。
